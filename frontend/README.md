# SEWFIT Frontend Application

Modern web interface for the SEWFIT Smart Custom-Clothing Platform.

## Features
- **Customer Portal**: Browse clothing catalog, view tailor profiles, configure garment customizations, and manage body measurement profiles.
- **Tailor Portal**: Manage workshop bio, configure clothing products, set required measurement keys, track production stages (`CUTTING`, `SEWING`, `FITTING`), and perform quality checks.
- **Delivery Agent Portal**: Browse available pickup jobs, navigate pickup & delivery destinations, update transit status, and confirm delivery handovers.
- **Admin Dashboard**: Platform KPI analytics, tailor verification, complaints resolution, audit log inspection, and system settings.

## Getting Started

```powershell
cd frontend

# Install dependencies
npm install

# Start local dev server
npm run dev
```

The frontend will run locally with HMR. Connects to backend API at `http://localhost:3001`.
